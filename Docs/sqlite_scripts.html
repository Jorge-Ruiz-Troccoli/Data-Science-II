03
Eliminar y recrear con restricciones
AUTOINCREMENT, PRIMARY KEY y UNIQUE en SQLite
DDL
⚠ En SQLite se usa INTEGER PRIMARY KEY AUTOINCREMENT (no AUTO_INCREMENT como en MariaDB). Para iniciar desde 10 se inserta un registro con CustomerID = 9 y se elimina, o se usa la tabla sqlite_sequence.
SQLite
DROP TABLE IF EXISTS Customers;

CREATE TABLE Customers (
  CustomerID   INTEGER PRIMARY KEY AUTOINCREMENT,
  CustomerName TEXT,
  ContactName  TEXT,
  Address      TEXT,
  City         TEXT,
  PostalCode   TEXT,
  Country      TEXT UNIQUE
);

-- Iniciar el autoincrement desde 10
INSERT INTO sqlite_sequence (name, seq)
VALUES ('Customers', 9);

05
Consultas SELECT
Recuperar todos los registros o filtrar por columnas
SELECT
SQLite
-- Todos los registros
SELECT * FROM Customers;

-- Columnas específicas con filtro
SELECT CustomerID, CustomerName, Address
FROM   Customers
WHERE  CustomerID = 1;

Modificar un campo para un registro específico
DML
SQLite

07
Recrear tabla con CHECK y NOT NULL
Restricciones de integridad más estrictas
DDL
SQLite
DROP TABLE IF EXISTS Customers;

CREATE TABLE Customers (
  CustomerID   INTEGER PRIMARY KEY CHECK (CustomerID > 0),
  CustomerName TEXT,
  ContactName  TEXT    NOT NULL,
  Address      TEXT,
  City         TEXT,
  PostalCode   TEXT,
  Country      TEXT
);
08
Modificar columnas — ALTER TABLE
NOT NULL, DEFAULT y ampliación de longitudes
ALTER
⚠ SQLite tiene soporte limitado para ALTER TABLE — no permite modificar tipos ni restricciones existentes. La forma correcta es recrear la tabla con la nueva definición.
SQLite — patrón recomendado
-- 1. Crear tabla nueva con las restricciones deseadas
CREATE TABLE Customers_new (
  CustomerID   INTEGER PRIMARY KEY CHECK (CustomerID > 0),
  CustomerName TEXT    NOT NULL,
  ContactName  TEXT    NOT NULL,
  Address      TEXT    NOT NULL,
  City         TEXT    NOT NULL,
  PostalCode   INTEGER NOT NULL,
  Country      TEXT    NOT NULL DEFAULT 'Canada'
);

-- 2. Migrar datos
INSERT INTO Customers_new
  SELECT * FROM Customers;

-- 3. Reemplazar la tabla original
DROP TABLE Customers;
ALTER TABLE Customers_new RENAME TO Customers;

-- Agregar columna (esto sí es soportado directamente)
ALTER TABLE Customers ADD COLUMN Email TEXT;

10
Vaciar tabla — DELETE vs TRUNCATE
SQLite no tiene TRUNCATE — se usa DELETE
AVANZADO
⚠ SQLite no implementa TRUNCATE TABLE. El equivalente es DELETE FROM sin cláusula WHERE. Para resetear el AUTOINCREMENT también hay que limpiar sqlite_sequence.
SQLite
-- Equivalente a TRUNCATE: elimina todos los registros
DELETE FROM Customers;

-- Resetear el contador AUTOINCREMENT (opcional)
DELETE FROM sqlite_sequence WHERE name = 'Customers';
11
Actualizar y eliminar registros
UPDATE y DELETE con WHERE
DML
SQLite
-- Actualizar nombre
UPDATE Customers
SET    CustomerName = 'Alfred Schmidt'
WHERE  CustomerID = 1;

-- Eliminar registro específico
DELETE FROM Customers
WHERE  CustomerID = 1;

-- Verificar resultado
SELECT CustomerID, CustomerName, Address
FROM   Customers;
Diferencias clave con MariaDB
Lo que cambia al usar SQLite en lugar de MariaDB
AUTOINCREMENT · sin MODIFY · sin TRUNCATE · TEXT > VARCHAR
