02
Sentencia CASE — clasificar por cantidad
Lógica condicional dentro de un SELECT
CASE
WHEN ... THEN
Condición a evaluar y valor a devolver si se cumple
ELSE
Valor por defecto si ninguna condición se cumple
END AS
Cierra el CASE y nombra la columna resultante
SQLite
SELECT
  OrderID,
  Quantity,
  CASE
    WHEN Quantity >  30 THEN 'Mayor 30'
    WHEN Quantity =  30 THEN 'Igual 30'
    ELSE                       'Menor 30'
  END AS TextoCantidad
FROM OrderDetails;

03
GROUP BY · HAVING · ORDER BY
Países con más de 2 órdenes, ordenados de mayor a menor
AGRUPACIÓN
GROUP BY
Agrupa filas con el mismo valor en una columna
HAVING
Filtra grupos — como WHERE pero sobre agregaciones
ORDER BY DESC
Ordena el resultado de mayor a menor
SQLite
SELECT
  Country          AS Pais,
  COUNT(OrderID)   AS Total
FROM   OrderDetails
GROUP  BY Country
HAVING Total > 2
ORDER  BY Total DESC;

Country44
Country33
Country13
Solo aparecen los países con más de 2 órdenes. El resto queda excluido por el HAVING.
04
Combinado — CASE dentro de GROUP BY
Bonus: contar cuántas órdenes hay por categoría
BONUS
SQLite
SELECT
  CASE
    WHEN Quantity >  30 THEN 'Mayor 30'
    WHEN Quantity =  30 THEN 'Igual 30'
    ELSE                       'Menor 30'
  END AS Categoria,
  COUNT(*) AS CantOrdenes
FROM     OrderDetails
GROUP BY Categoria
ORDER BY CantOrdenes DESC;
Orden de ejecución SQL
El motor procesa las cláusulas en este orden interno
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
